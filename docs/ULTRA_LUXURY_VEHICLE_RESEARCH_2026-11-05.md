# Ultra-luxury vehicle catalogue — 5 November 2026

This curated selection adds 40 distinct make/model choices to the previous 80.
It prioritises high-end and exotic vehicles including low-volume imports; it is
not a sales ranking. Australian price evidence is used where available; some
variants start above A$200,000 even if other variants of that model cost less.
Prices and import availability can change.

The icon depicts the noted body or variant; the included years are conservative
catalogue coverage, not a statement that production started or ended in those
years. Unsupported years and manual entries keep the generic icon. Images are
stylised original AI illustrations guided by reference photographs, not
manufacturer-certified replicas. Options, variants and facelift timing can differ.

## Local verification — 5 November 2026

`npm test` passed 253 tests, including a backend save and invalid-year rejection
for the new Ferrari, uniqueness checks for all 120 entries, and artwork lookup
for every supported year and colour. `npm run lint` and `npm run build` passed.
The initial contact-sheet generation exceeded the WebP height limit; splitting
it into two sheets resolved the issue and the command above passed on retest.
All 240 new assets were checked for transparent corners; each source sheet was
reviewed against its reference and checked for vehicles crossing cell edges.

`GUMWHEEL_TEST_TILES=1 /tmp/gumwheel-notification-check-env/bin/python scripts/check-vehicle-catalogue.py`
passed with synthetic accounts and mocked APIs at 320, 390, 844 and 1440px.
The Ferrari profile and driver/rider journey views were visually reviewed on
mobile and desktop. Public map tiles loaded inconsistently during review.
Physical-device and authenticated production flows have not been tested.
