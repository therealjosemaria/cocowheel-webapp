# Affordable vehicle catalogue — 5 November 2026

Forty additional distinct make/model/body choices extend the existing catalogue
to 80 without changing the original IDs or year coverage. The choices are a
curated mix of lower-cost and widely purchased mainstream models, not a strict
price or sales ranking; there is no claim that all 40 are the cheapest cars.
The owner asked for one recent Australian-market body per model, with the same
six colours and the existing Other/manual generic-car fallback.

## Local verification — 5 November 2026

`npm test` passed 253 tests, including backend save and validation for the new
MG3, unique make/model and ID checks, and artwork lookup for every supported
colour/year. `npm run lint` and `npm run build` passed. The first sandboxed
build could not bind its helper port; the build passed with loopback access.
`GUMWHEEL_TEST_TILES=1 /tmp/gumwheel-notification-check-env/bin/python scripts/check-vehicle-catalogue.py`
passed with mocked APIs at 320, 390, 844 and 1440px. Profile and both private
roles were reviewed on mobile and desktop with an MG3 and OSM map tiles; public
tile availability varied. Generated colour sheets were inspected, and their
cell boundaries and transparent corners checked. No production journey was
changed for testing. Physical-device and signed-in production checks are pending.
