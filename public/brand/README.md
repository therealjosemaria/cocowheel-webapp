# GUMWHEEL header artwork

`gumwheel-bubble-wheel.png` is the original 1774×887 transparent PNG generated
with the built-in image-generation tool on 16 October 2026 and approved by the
project owner. It is not a downloaded Rawpixel asset. It is raster, not SVG.

Prompt brief: a matching pair of softly lit 3D icons, a round pastel-pink bubble
of chewing gum and a front-facing black tyre with five silver alloy spokes;
equal visual diameters, transparent background, no text, brands or watermark.

The shared header uses Next Image resizing and CSS framing to preserve this
exact approved illustration. No third-party image hosting is required.
